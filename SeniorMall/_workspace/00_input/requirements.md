# SeniorMall 요구사항

## 프로젝트
시니어 쇼핑몰 (SeniorMall)

## 대상 사용자
60세+ 시니어 사용자 — 디지털 친숙도가 낮고 큰 글씨·단순 UI가 필수

## 핵심 기능
- 상품 카탈로그 (카테고리별 탐색, 검색)
- 장바구니 (수량 조절, 합계 표시)
- 주문/결제 (단순 3단계 플로우)
- 회원관리 (회원가입, 로그인, 마이페이지)
- 주문 내역 조회
- 관리자 패널 (상품 등록/수정/삭제, 주문 관리)

## 시니어 특화 요구사항
- 기본 글꼴 크기 18px 이상
- 버튼 최소 높이 48px
- 고대비 색상 (WCAG AA)
- 단순 네비게이션 (최대 3단계)
- 명확한 에러 메시지 (색깔+텍스트 병기)
- 로딩 상태 명시 ("불러오는 중...")

## 기술 스택
- Frontend: React 18 + Vite + CSS Modules
- Backend: Node.js + Express 4
- ORM: Prisma + PostgreSQL
- Auth: JWT (access 1h + refresh 7d)

## 특이사항
- MVP 기준 — 복잡한 결제 게이트웨이 없이 주문 생성까지
- 이미지는 multer 로컬 저장
- 시드 데이터: 상품 10개(건강/생활/식품 카테고리), 일반 사용자 1명, 관리자 1명
